# Clout Ranch — Master Vision (Best-on-Roblox bar)

## One-liner
Steal-idle pet tycoon where **clout is the resource**, **Aura Flex is the spectacle**, and **every week internet culture becomes a new pet** — without ripping IP.

## Pillars (non-negotiable)
1. **Instant read** — 10 seconds to understand: pets print cash, unlocked ranches get stolen, Flex is a show.
2. **Fair heat** — VIP buys *time* and *comfort*, never “you can’t play.” Steal vs VIP still works ≥30%.
3. **Daily ritual** — streak + 3 quests + trend banner so returning feels dumb not to.
4. **Clip bait** — every Secret steal / podium finish is a vertical-video moment.
5. **Social gravity** — parties, killfeed, ranch showcases; friends make income safer and Flex funnier.
6. **Live culture** — weekly original trend pets; game never stuck in one meme season.
