# Clout Ranch — Revenue + Daily Addiction Design

## Daily loop (why they open every day)
1. **Streak claim** (30s) — escalating cash/luck/aura; break = soft reset with 1 grace day
2. **Featured Carpet pet** — SeasonService weekly Secret window (FOMO)
3. **Defend overnight income** — pets kept printing; fear of steal drives return + VIP lock spend
4. **Battle Pass XP** — daily XP cap soft; miss a day = fall behind prestige track (not power-locked)
5. **Aura Flex clip moments** — social reason to hop on with friends

## Monetization ladder (edge + FOMO, free-to-win core)

## Anti-patterns we avoid
- Doomscroll-for-power feeds (Roblox banned)
- Licensed meme characters / NFL IP
- Hard paywall on steal/rebirth
- Infinite admin spam as the product

## KPIs
D1 ≥ 30%, D7 ≥ 10%, payer conversion ≥ 3%, ARPPU via VIP+BP+limiteds
